# Covered Bridge Home Loans (`/home-loans`) — Coming Soon

A simple branded holding page: the heading **COVERED BRIDGE HOME LOANS** and a **Coming Soon** status. The menu link to this page reads **Home Loans**; in GHL, name the page "Home Loans" too. No offers, pricing, forms or dates.

Create a new GHL page at `/home-loans`, then paste these blocks in order, each into its own full-width Custom HTML/JavaScript element (0 padding, no background):

| # | File | Block |
|---|---|---|
| 1 | `sections/00-header-capital.html` | Header: Marketing Services, Business Funding, Home Loans, High Converting Leads (the current page is highlighted) |
| 2 | `pages/home-loans/01-home-loans-soon.html` | Coming Soon body (`.cbb-lsoon`) |
| 3 | `sections/06-footer.html` | Footer (same as every page) |

The header picks the highlighted link from the page address, so it shows on the published page; GHL's editor preview uses a different address and shows no highlight. The phone link calls 814-893-1075.

Both this block and the header are generated by `python3 scripts/build-variants.py`; edit that script rather than the HTML files.
